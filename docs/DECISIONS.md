| 024 | 2026-08-22 | `legal/registry.json` records a SHA-256 of every document's bytes                                         | Consent to a document nobody can reproduce is not consent, so the hash is stored with the acceptance record and shown on the published page.                                                                                                                                                                                                                                                                                                                                                                |
| 025 | 2026-08-22 | The copy lint has a reasoned block-suppression escape hatch                                               | The Badge Licence has to name the phrases it prohibits; the alternative was exempting the whole file, which would have removed the check from the document that needs it most.                                                                                                                                                                                                                                                                                                                              |

| 027 | 2026-08-22 | The scope guard is enforced in-process _and_ by the container's egress allowlist                          | A model that can be talked into fetching a URL is only stopped by something below it, and a container allowlist cannot express "this customer authorised these hosts" — neither layer is sufficient alone.                                                                                                                                                                                                                                                                                                  |
| 028 | 2026-08-22 | Requests are checked against the _resolved_ address, not the hostname                                     | A customer's domain can point at a link-local or private address, deliberately or by rebinding, and a hostname check would wave it through to the cloud metadata endpoint.                                                                                                                                                                                                                                                                                                                                  |
| 029 | 2026-08-22 | Redirects are followed manually, one hop at a time                                                        | An automatically followed redirect is a request the guard never saw, and could carry the runner to a host nobody authorised.                                                                                                                                                                                                                                                                                                                                                                                |
| 030 | 2026-08-22 | The agentic loop is written out rather than delegated to the SDK's tool runner                            | Every iteration has to re-check the cost ceiling and route each tool call through the scope guard, which is control the runner does not expose.                                                                                                                                                                                                                                                                                                                                                             |
| 031 | 2026-08-22 | Exploration and structured extraction are separate model calls                                            | Asking a model to hold an output schema in mind while it is navigating a browser degrades both; separating them also means a malformed extraction does not lose the exploration.                                                                                                                                                                                                                                                                                                                            |
| 032 | 2026-08-22 | A finding citing an evidence id we did not mint is dropped in code                                        | "No finding without evidence" cannot be a prompt instruction, because the thing being constrained is the output of the prompt.                                                                                                                                                                                                                                                                                                                                                                              |
| 033 | 2026-08-22 | A ceiling breach is never retried                                                                         | A run stopped for reaching its cost or scope limit will not succeed on a second attempt; retrying it spends money to break the same rule twice.                                                                                                                                                                                                                                                                                                                                                             |
| 034 | 2026-08-22 | Tests use a scripted model transport, never the real API                                                  | A test suite that costs money and returns something different each run is a test suite nobody runs.                                                                                                                                                                                                                                                                                                                                                                                                         |
| 035 | 2026-08-22 | Evidence is many-to-many with findings, via a join table                                                  | One HTTP exchange commonly evidences several findings; a single foreign key silently detached it from all but the last, leaving findings unevidenced.                                                                                                                                                                                                                                                                                                                                                       |
| 036 | 2026-08-22 | The authorisation gate is checked at dispatch and again before persisting                                 | A customer can withdraw authorisation while a run is in flight, and if they do, that run's output must not become a report.                                                                                                                                                                                                                                                                                                                                                                                 |
| 037 | 2026-08-22 | Intake screening defers to a human rather than guessing, and never fails open                             | A wrongly refused customer is a real harm and so is a wrongly accepted one; the difference is that a human can resolve the first in a day.                                                                                                                                                                                                                                                                                                                                                                  |
| 038 | 2026-08-22 | Cost records are unreadable to reviewers as well as to customers                                          | A reviewer who can see what an assessment cost us is a reviewer with a commercial signal in front of them.                                                                                                                                                                                                                                                                                                                                                                                                  |
| 039 | 2026-08-22 | pg-boss on the same Postgres, rather than a hosted queue                                                  | One fewer vendor and one fewer dashboard, and the jobs live where the data lives.                                                                                                                                                                                                                                                                                                                                                                                                                           |
| 040 | 2026-08-22 | The engine exposes a second entry point for the parts the web app uses                                    | Ownership verification and intake screening run in the console; a single barrel export would pull a browser driver into the Next.js bundle graph.                                                                                                                                                                                                                                                                                                                                                           |
| 041 | 2026-08-22 | A free report shows the same score, band and dimension breakdown as a paid one                            | Withholding the number would look exactly like hiding how the rubric works; what payment buys is the detail and the evidence, not a different result.                                                                                                                                                                                                                                                                                                                                                       |
| 042 | 2026-08-22 | The scope statement and "what was not assessed" are never withheld at any tier                            | A thinner report is fine; a report whose silence about coverage reads as a clean result is not.                                                                                                                                                                                                                                                                                                                                                                                                             |
| 043 | 2026-08-22 | Redaction strips evidence from the objects, not just from the template                                    | A renderer that forgets a conditional must not be able to leak what a customer did not buy.                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 044 | 2026-08-22 | The report document is entirely self-contained                                                            | It is the same document Playwright prints to PDF, and a PDF that fetches a stylesheet renders differently depending on the network.                                                                                                                                                                                                                                                                                                                                                                         |
| 045 | 2026-08-22 | The PDF is generated once, after review, and served from storage                                          | A downloaded PDF is a record; re-rendering on each request would let two copies of "the same" report differ, and the one shown to an investor would be the one nobody could reproduce.                                                                                                                                                                                                                                                                                                                      |
| 046 | 2026-08-22 | Report assembly lives in `packages/report`, taking a minimal SQL interface                                | The worker and the console both need it, and two copies would eventually disagree about what a report says. | 047 | 2026-08-22 | The console reads reports over SQL under `set local role authenticated`                                   | Assembly is one query and four REST round trips. Running it as the caller keeps one code path and leaves row-level security in charge; the service-role key is deliberately absent from that file.                                                                                                                                                                                                                                                                                                          |
| 048 | 2026-08-22 | Payments go through a `PaymentProvider` interface with a signing fake                                     | A payments test that only runs when someone exports a secret is a payments test that does not run. The fake signs with a real HMAC, so verification is exercised rather than bypassed.                                                                                                                                                                                                                                                                                                                      |
| 049 | 2026-08-22 | Webhook idempotency is a unique constraint on the provider's event id                                     | Providers deliver events more than once. A flag we remember to check is not idempotency.                                                                                                                                                                                                                                                                                                                                                                                                                    |
| 050 | 2026-08-22 | The raw request body is verified before anything parses it                                                | Verifying a re-serialised object verifies our serialiser, not the provider.                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| 051 | 2026-08-22 | Our own `assessment_requests` table replaces pg-boss as the queue                                         | Deviation from PART 5, for one reason: a customer needs to see that their assessment is queued, and a queue inside a library's private schema is invisible to row-level security. | 052 | 2026-08-22 | An unauthorised target is never retried                                                                   | Retrying would mean attempting to test something we may not test, twice.                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| 053 | 2026-08-22 | The entitlement decision is recorded on the request row, not just acted on                                | A customer who asks in six months why a run was refused deserves the answer they were given at the time, not one recomputed from a plan that has since changed.                                                                                                                                                                                                                                                                                                                                             |
| 054 | 2026-08-22 | Reports are generated by a sweep, not by a message from the console                                       | An approval whose enqueue failed would leave a customer with a report that never appears and no trace of why. A sweep is self-healing, and it also picks up free-to-paid upgrades.                                                                                                                                                                                                                                                                                                                          |
| 055 | 2026-08-22 | A one-off purchase attaches to the app it was bought for                                                  | Buying a deep report on one application should not silently upgrade every other application in the workspace.                                                                                                                                                                                                                                                                                                                                                                                               |
| 056 | 2026-08-22 | A badge signature attests a historical fact, never current standing                                       | The assessment happened; that does not stop being true when a badge is revoked, so the signature keeps verifying. Whether the badge is live is a question only our origin can answer, and conflating the two is how someone ends up trusting a revoked badge.                                                                                                                                                                                                                                               |
| 057 | 2026-08-22 | The signed payload has a fixed field set and a published canonicalisation                                 | An extra field would be signed by one implementation and ignored by another, which is how signature schemes quietly stop meaning anything. The exact serialisation is published in the API response, not only in our code.                                                                                                                                                                                                                                                                                  |
| 058 | 2026-08-22 | Scores are fixed to one decimal before signing                                                            | Otherwise 82 and 82.0 produce two different signatures for one assessment.                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| 059 | 2026-08-22 | The algorithm is fixed in code and never read from the badge                                              | "Let the token tell you how to verify it" is how signature schemes get broken.                                                                                                                                                                                                                                                                                                                                                                                                                              |
| 060 | 2026-08-22 | Retired public keys stay published forever                                                                | Removing one would silently break every badge it signed, and a verifier that suddenly fails cannot tell "forged" from "VibefyCode tidied up its keys".                                                                                                                                                                                                                                                                                                                                                      |
| 061 | 2026-08-22 | Only the worker holds the badge signing key                                                               | Every web instance that could sign is another place the one key whose loss ends the business can leak from.                                                                                                                                                                                                                                                                                                                                                                                                 |
| 062 | 2026-08-22 | The badge image is cached for five minutes                                                                | Long enough to be cheap, short enough that a revocation reaches every embedded instance within minutes, which is what the brief promises.                                                                                                                                                                                                                                                                                                                                                                   |
| 063 | 2026-08-22 | An unknown badge id renders as "revoked", not as a 404 image                                              | On someone's website a broken image gets ignored; a mark that says "not currently verified" does not.                                                                                                                                                                                                                                                                                                                                                                                                       |
| 064 | 2026-08-22 | Origin telemetry is capped at one event per badge, per origin, per hour                                   | Telemetry that grows with pageviews is a bill, not a signal. Detecting a mismatch needs one event, not thousands.                                                                                                                                                                                                                                                                                                                                                                                           |
| 065 | 2026-08-22 | Badge issuance is a sweep, like reports                                                                   | Three things must be true before a badge exists — approval, the rubric gate, licence acceptance — they happen at different times in different processes, and a sweep notices when the last one lands.                                                                                                                                                                                                                                                                                                       |
| 066 | 2026-08-22 | A continuous plan gets a three-month badge; a one-off gets twelve                                         | Monitoring is what maintains a badge, so a maintained one can expire sooner and be renewed. A badge bought outright is not rented, and is not suspended when an unrelated subscription lapses.                                                                                                                                                                                                                                                                                                              |
| 067 | 2026-08-22 | The runtime badge and the brand masters share one renderer                                                | They were two implementations of the same artwork, which is precisely how a mark ends up looking different on a customer's site than in our own header.                                                                                                                                                                                                                                                                                                                                                     |
| 068 | 2026-08-22 | The rubric version and assessment date live in the badge's accessible name, not inside the mark           | PART 0.5 permits either, and putting them in the artwork would mean altering the mark per application — which the same section forbids.                                                                                                                                                                                                                                                                                                                                                                     |
| 069 | 2026-08-22 | Drift compares rule-and-dimension keys, never finding titles                                              | A title is model-written prose, so a reworded sentence would read as a fixed bug and a fixed bug as a new one.                                                                                                                                                                                                                                                                                                                                                                                              |
| 070 | 2026-08-22 | Withheld findings are invisible to the comparison in both directions                                      | A withheld finding never reached the customer and never moved the score; counting one as resolved would credit a fix that never happened, and counting one as new would suspend a badge over an accusation we ourselves refused to publish.                                                                                                                                                                                                                                                                 |
| 071 | 2026-08-22 | Material-regression rules are data, each carrying the sentence the customer is shown                      | A rule that has to be reverse-engineered from a branch cannot be quoted back in an appeal, and a suspension nobody can explain is a suspension nobody can contest.                                                                                                                                                                                                                                                                                                                                          |
| 072 | 2026-08-22 | A verdict reports every reason it found, not the first                                                    | A notice that lists one of four problems invites the customer to fix that one and then ask why the badge is still down.                                                                                                                                                                                                                                                                                                                                                                                     |
| 073 | 2026-08-22 | A badge is never suspended when the two assessments used different rubric versions                        | The score moved because we changed the standard. Charging the customer a badge for our own change would make every rubric release a trust event.                                                                                                                                                                                                                                                                                                                                                            |
| 074 | 2026-08-22 | `drift_reports` is append-only, with a check constraint requiring a reason for any material verdict       | The drift report is the justification for taking someone's badge down, and a justification that can be edited afterwards is not one.                                                                                                                                                                                                                                                                                                                                                                        |
| 075 | 2026-08-22 | Monitoring's verdict modules carry the same compile-time commercial-data ban as scoring                   | This is the second place a commercial fact could quietly change an outcome — "their subscription lapsed, call it a regression" — and the consequence is worse, because it takes a live badge down.                                                                                                                                                                                                                                                                                                          |
| 076 | 2026-08-22 | Cadence lives in its own module, and the verdict modules may not import it                                | How often a paying customer is looked at is coverage. | 077 | 2026-08-22 | Every alert carries a dedupe key with a unique index behind it                                            | A monitoring system that sends the same warning every thirty seconds trains people to ignore all of them, and the one that mattered arrives in a folder nobody opens.                                                                                                                                                                                                                                                                                                                                       |
| 078 | 2026-08-22 | Liveness suspends only after a run of consecutive failures, and restores automatically                    | Taking a working customer's badge down for one timeout is its own harm, and an application that comes back should not need a support ticket to get a badge back that was never withdrawn on the merits.                                                                                                                                                                                                                                                                                                     |
| 079 | 2026-08-22 | A 4xx response counts as alive                                                                            | The origin answered. Whether a particular path exists is an assessment question, not a liveness one.                                                                                                                                                                                                                                                                                                                                                                                                        |
| 080 | 2026-08-22 | The liveness restore matches on the suspension reason we wrote                                            | So a badge a reviewer suspended on the merits, or one suspended for a regression, is left exactly where the person who suspended it put it.                                                                                                                                                                                                                                                                                                                                                                 |
| 081 | 2026-08-22 | Suspension gets its own reason column, separate from revocation                                           | They were sharing one, which meant a customer whose site was down for six hours could be told their badge was "revoked" — a statement about them rather than about a bad afternoon.                                                                                                                                                                                                                                                                                                                         |
| 082 | 2026-08-22 | A scheduled re-assessment stamps the application before the run, not after                                | Otherwise a permanently failing application is re-queued on every sweep, for ever, at full cost.                                                                                                                                                                                                                                                                                                                                                                                                            |
| 083 | 2026-08-22 | The scheduled re-assessment query re-checks authorisation in SQL                                          | The promise is that authorisation is checked every time, not once at the start of the relationship. | 084 | 2026-08-22 | The alert inbox in the console is the record; email is a best-effort copy                                 | A customer who never opens an email must still be able to find out why their badge went down.                                                                                                                                                                                                                                                                                                                                                                                                               |
| 085 | 2026-08-22 | A customer may write `read_at` on an alert and nothing else                                               | The grant is column-level. What we told someone, and when, is no more theirs to edit than it is ours.                                                                                                                                                                                                                                                                                                                                                                                                       |
| 086 | 2026-08-22 | A policy profile is applied over a score, never to it                                                     | An organisation's bar and the rubric's bar are different questions. | 087 | 2026-08-22 | A dimension the assessment did not score fails a profile that requires it                                 | Silence about a requirement reading as a pass is the exact failure mode this product exists to fix.                                                                                                                                                                                                                                                                                                                                                                                                         |

| 089 | 2026-08-22 | Only the hash of an invitation token is stored                                                            | An invitation link is a credential: whoever holds it joins the workspace. | 090 | 2026-08-22 | An invitation checks the signed-in address as well as the token                                           | A forwarded link is a link that works for the wrong person, and "we sent it to the right inbox" is not a defence anyone accepts afterwards.                                                                                                                                                                                                                                                                                                                                                                 |
| 091 | 2026-08-22 | Ownership is never invited and never granted by single sign-on                                            | The seat that can delete everything is granted deliberately, by an existing owner, to an account that already exists. | 093 | 2026-08-22 | An SSO domain claim is verified by DNS TXT and is unique platform-wide                                    | An unverified claim would let anyone route another company's staff logins through their own identity provider; a shared claim would be the same thing with an extra step.                                                                                                                                                                                                                                                                                                                                   |

| 096 | 2026-08-22 | White-label is a cover block, not an attribution                                                          | Every report still states that VibefyCode performed the assessment against the published rubric and that the agency did not score the application.
