## Known gaps in shipped code

Things that work but are narrower than they will need to be. Each is here so it cannot be
mistaken for finished.

| Gap                                                                     | Where                                                                  | Why it is acceptable for now                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ----------------------------------------------------------------------- | ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| The authenticated console is not accessibility-scanned                  | `pnpm check:a11y`                                                      | Twelve public pages are scanned on every CI run, plus the report, the badge and the alert email in `pnpm test`. Reaching the console needs a live auth service, which the local harness does not run — so the pages a customer spends most time on are covered by the contrast gate and by review, not by axe.                                                                                                                                                                                          |
| The webhook endpoint is not registered with the provider                | Resend dashboard                                                       | `POST /api/email/webhook` verifies and applies bounces and complaints, and refuses everything it cannot prove came from the provider. Pointing Resend at it, and setting `RESEND_WEBHOOK_SECRET`, is an operator step that follows the domain decision.                                                                                                                                                                                                                                                 |
| The journey test substitutes one stage in its second act                | `tests/journey.test.ts`                                                | A loopback fixture is served over plain HTTP, which is a critical finding forever, so an application that _passes_ cannot be built out of one. The first act runs the real engine against the real fixture; the later acts substitute the observation and keep every step downstream of it. Closing this needs a fixture served over TLS.                                                                                                                                                               |
| Only the plans carry a detailed explanation                             | `apps/web/components/disclosure.tsx`                                   | The `Disclosure` component and the "what happens, what is not included, how to stop" shape exist and are used on every plan. The other things a customer buys into — an assessment depth, monitoring, a policy profile, the badge licence — still explain themselves in a sentence. Same component, one page at a time.                                                                                                                                                                                 |
| The triage does not read the previous score from the database           | `apps/web/app/review/page.tsx`                                         | `triageAssessment` accepts a `previousScore` and raises a large-move flag from it, and the queue does not yet fetch one. The rule works and is tested; the queue simply passes nothing, so that one flag never fires there. A second query per assessment is the wrong fix — it wants a view.                                                                                                                                                                                                           |
| The trust check has no rate limit                                       | `/trust-check`                                                         | Anyone can make the server fetch a page of their choosing, and nothing stops them doing it in a loop. The request itself is tightly bounded — one GET, no private addresses, 10s, 2MB — so the exposure is our own bandwidth and somebody else's logs, not our network. A limit belongs at the edge (the hosting platform), not in a bespoke counter.                                                                                                                                                   |
| The trust check reads one page, not the site                            | `packages/trustcheck`                                                  | A cancellation route behind a sign-in, or terms on a second page, are invisible to it — and it says so in every result. Following one level of policy links would find much more, and would need a crawl budget and a robots.txt reading that this deliberately does not have yet.                                                                                                                                                                                                                      |
| Public review sources are not consulted                                 | `packages/trustcheck`                                                  | Anré asked for reviews and reputation alongside the page check. Those come from third-party sources with their own terms, their own accuracy problems, and their own defamation exposure when quoted about a named company. Worth doing, worth doing carefully, and a separate decision from the page check.                                                                                                                                                                                            |
| Marketing services are not built                                        | M8                                                                     | Requested, and blocked on the same thing M8 has always been blocked on: it must sit visibly outside the wall that keeps commercial data away from scores. A rater that also sells marketing is the conflict this product exists to solve, so the separation has to be structural rather than promised.                                                                                                                                                                                                  |
| SPF, DKIM and DMARC are not set up                                      | The sending domain                                                     | Blocked on the domain decision. Without them the notices land in spam, and a notice in spam is not a notice.                                                                                                                                                                                                                                                                                                                                                                                            |
| EAS build and store submission are not configured                       | `apps/mobile`                                                          | The app runs in Expo Go and a development build. `eas.json`, signing credentials and store listings need the Apple and Google accounts, which follow the legal-entity decision.                                                                                                                                                                                                                                                                                                                         |

| A double-click can open two checkouts                                   | `apps/web/app/console/billing/actions.ts`                              | The idempotency key is fresh per attempt because Paystack rejects a reused transaction reference, so an abandoned checkout must not poison the next try. The game pass records them as unscored observations and says so rather than folding them into the nearest criterion that almost fits. Their proper home is a rubric 1.1.0, which is a deliberate piece of work: a published version is immutable, and every existing badge stays on the version it was scored against. |

Reaching it needs a seeded badge in the a11y harness.                                                                                                                                                                               |
| The design survey reads one page, not the application                   | `packages/engine/src/stages/design-checks.ts`                          | It runs against the landing page at desktop width. Inconsistency between pages — the signed-in screens looking nothing like the marketing site — is the commonest form of the problem and is invisible to a single-page survey. Doing it properly means a crawl, which needs a decision about scope and cost.                                                                                                                                                                                           |
| Alignment and rhythm are not measured                                   | `packages/engine/src/stages/design-checks.ts`                          | Elements that are almost-but-not-quite aligned, and vertical rhythm that drifts, are two of the loudest visual defects and neither is counted here. | Advertising rates are placeholders                                      | `config/pricing.json`                                                  | $1 500 per 30 days for the directory, $750 for the other two. | There is no way to buy a placement without writing to us                | `/advertise`                                                           | Deliberate for now — a placement nobody looked at is the exact failure this company cannot have, and a checkout is how that happens. | A placement's period is not enforced against its invoice                | `public.sponsorships`                                                  | The dates decide what appears and the invoice is recorded beside them, but nothing checks that a live placement was actually paid for. Today an operator approves both by hand and sees both on one screen; when this is wired to a checkout that gap becomes a real one.                                                                                                                                                                                                                               |

The prompt-driven stage has not: this environment has no model key, so what a model does with a canvas game — whether it can hold one long enough to say anything the measurements do not already say — is still unknown. The stage is written and gated; it needs one real run with a key set.                                                                                                   |
| Time-to-playable is a lower bound, not a measurement                    | `packages/engine/src/stages/game-checks.ts`                            | Playability is defined as the first continuous run of animation frames, which a title card also satisfies. Every finding says so. Doing better means recognising when a game is accepting input, which is not generally possible from outside without knowing the game.                                                                                                                                                                                                                                 |
